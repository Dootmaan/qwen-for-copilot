Your Qwen models appear in the Copilot Chat model picker as soon as the extension is active.

Built-in models include:

- `qwen3-coder-plus`
- `qwen-max`
- `qwen-plus`
- `qwen-turbo`
- `qwen-vl-plus`

Until you run `Qwen: Set API Key`, the models appear with a reminder to set your key. If you do not see them right away, the model list may be long — scroll down and look for the Qwen models.

To control reasoning, use `qwen-copilot.thinking`. To add your own model ids, use `qwen-copilot.customModels`.
